# Paperplane Shop (Trustline demo repository)

A tiny storefront with planted external references, used to demo Trustline.
Every `trustline-demo-*` name is fictional and chosen to be unregistered.
The deploy workflow is disabled (`if: false`, manual trigger only) so GitHub never runs the planted `curl | bash` line.
Nothing here is meant to be built or deployed.
